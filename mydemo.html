My Awful Demo

After learning the various techniques, I wanted to make my own loader to rival the Counterpoint ones that inspired me. Clearly I didn't get very far, but I guess we all start somewhere.

Blue Fade and Meow, the two named parts
As written. y := round(30*sin(x)) feeds the loop counter straight to sin, so it is 1, 2, 3… radians. A full cycle takes 2π ≈ 6.28 iterations, and each iteration moves the text 4 pixels right, so the wave has a wavelength of about 25 pixels on a 320-pixel screen. It does not wave. It vibrates, and the amplitude is ±30, which is bigger than the text is tall. I probably didn't realize the mathematical silliness, but liked how it looked and kept it as is.
The obvious fix, and it is a disappointment. Convert to degrees and the loop covers x = 1..180, which is half a cycle, except the text runs off the right edge at x = 80, because x*4 reaches 320 there. So only 80° of arc is ever on screen: 0.22 of a cycle. The text glides downward and off the edge. The remaining 100 iterations run entirely off-screen with delay(20) each, two seconds of nothing. This is what makes the "obvious" correction unconvincing as a reconstruction of intent.
Matched to what is actually visible. The text is on screen for x = 1..80, so x*pi/40 puts exactly one full cycle in that span: down, over, up, and out at the same height it came in. This is a guess at intent, not a recovered line. The file says sin(x) and nothing else survives to contradict it. It is here because it is the version that makes the loop bounds, the 4-pixel step and the ±30 amplitude all agree with each other, which none of the others do. Note the amplitude still is ±30 against a 400-row screen, so it reads as a gentle arc rather than a wave; copy_bitmap restores a 39×9 box each step, and at this amplitude the boxes overlap cleanly. Tick "leave a trail" to see the path.

The first one shaped like a demo

Everything before this is one effect in one file. MYDEMO has two named parts behind comment banners (Blue Fade and Meow) which is a demo's structure rather than a program's. The name says the same thing. It is forty minutes before I opened the year-old BOX, on the evening that becomes the busiest stretch in the archive.

Page 0 as a background store

The real step forward is invisible: it keeps a clean copy of the background on another Mode X page and restores only the rectangle it dirtied. Three months earlier MIMSY cleared and repainted.

Over half the animation happens off-screen

The Meow loop runs for x := 1 to 180 and places the text at x*4. The screen is 320 pixels wide.

xx*4
14first frame
80320the text reaches the right edge
180720400 pixels past it

101 of the 180 iterations draw nothing you can see, and each one still runs its delay(20), so the program spends about two seconds animating text that left the screen. The status line under the demo says so as it happens because otherwise the second half just looks like the program hanging.

It is the same shape of mistake as the wave itself. Both come from writing a loop bound that felt right (180 for half a circle, 180 for a nice long run) without checking it against the width of the thing it was drawing into.
