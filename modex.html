Enter Mode X

One of my best finds on entry 02 was Mode X. Aside from the library being genuinely useful, it included demo code that I spent ages digging through to try to understand. The first demo below is their demo out of the box, and the second is my own stripped down version.

pas/TEST5.PAS: 16 May 1995, 15,873 bytes. Not mine, and worth naming properly. The package is MODEX104, release 1.04 of 14 March 1993, a library of Mode X assembly routines by Matt Pritchard, placed by him in the public domain. Its README credits two more people: Michael Abrash "He told us all how to do it in the first place" and Scott Wyatt, "He ported the Main Demo code to Turbo Pascal." TEST5.PAS is Scott Wyatt's file, and obj/MODEX2.OBJ in the archive is Pritchard's MODEX.OBJ renamed (5,208 bytes, matching the packing list to the byte). Abrash → Pritchard → Wyatt. It shows off everything the library could do: a 360×240 virtual page larger than the 320×200 display, three pages, hardware panning, page flipping, transparent sprite blits, and palette cycling. The labels down the left are a list of its own entry points. The panning is the part worth watching. Nothing moves. Set_Window rewrites the CRTC start address and the card begins reading video memory somewhere else; no pixels are copied, no frame is redrawn. Tick the box to show the whole page and you can watch the window slide over a picture that is standing perfectly still. Sixty-four sprites bounce around on top, drawn onto whichever page is about to be displayed and erased from the other one by copying 16×16 boxes back from page 2, the clean master. That is why there are three pages and not two. And down in the loop are four lines that matter more than anything else here - see the next entry.
pas/JTEST.PAS: 2,771 bytes, .BAK 10 June 1995. Page_Demo with the sixteen label lines, the sixty-four sprites and the keyboard handler deleted. What is left is the fan, the panning and the chaser, and it runs unchanged. This is where entry 09's ALL.PAS's P10, P14 and P15 come from. The fan - DRAW_LINE(ScreenX div 2 - 1, ScreenY div 4, X, ScreenY-1, c+50) with the index walking a triangle 0..60..0 - and the four-line chaser over two palette banks at 50 and 150 are lifted into ALL fifteen months later, verbatim. What ALL changes is the bounce. Here the chaser's counters are tested: IF (SetColor = 60) OR (SetColor = 0) THEN SDir := -SDir, so they oscillate cleanly inside the bank. ALL's P14 drops that and writes p := p + 1; s := s + 2 on plain Bytes, so they run past 60, past 110, past 255, and wrap, scribbling values across all 256 registers at two different rates. That is where P14's moiré comes from, and it is an edit to this code, not a property of it. Two fossils left behind. The second palette bank at 150..210 is set up and written every single frame, and nothing on screen is ever drawn in it, here or in TEST5. And For c := 1 to 4 DO Set_Dac_Register(19+c, 63-(c*10), 0, 0) is still there, setting four shades of red for registers 20 to 23, which are the colors baked into the four sprite bitmaps I deleted. Dead palette entries for sprites that no longer exist. One more seam: ERROR_OUT writes int 10h in hex while the main block ends with my int 16 in decimal. Two hands, one file.

Where this entry sits in the archive

It arrives on the download morning. 1995-03-22 08:56, inside a 228 KB MODEX.ZIP - see entry 02.

The unit goes into the compiler the day before JTEST.BAK. utils/JMODEX.PAS is saved 1995-06-09 17:46 and TURBO.TPL is rebuilt at 17:51, five minutes later, with JMODEX installed into the standard unit library beside Borland's own. From that moment uses jmodex compiles with no paths set, and every Mode X program in the rest of the archive is one line away from building. JTEST.BAK is the following afternoon.

JTEST.PAS is re-saved three months after that, at 1995-09-21 17:59, the opening file of the twenty-one hours that also produced MYDEMO, BOX2 and the PATTERN1 → JUAN → DOODLE sequence. It is the busiest stretch in the collection; see entry 08.

And then the idiom leaves. The fan geometry and the two-bank spark chaser reappear in ALL fifteen months later as P10, P14 and P15 with one change, which is that the chaser's bounce is deleted and the counters are left to wrap. That edit is what produces P14's moiré. The note under the JTEST demo above has the code.

Procedure Page_Demo;
Begin
  XView_Change := 1;
  YView_Change := 1;
  XView := 1;
  YView := 1;
  Right := TRUE;
  ScreenX := 360;
  ScreenY := 240;
  PrevColor := 0;
  SetColor := 3;
  SDir := 1;
  PDir := 1;
  Str(0,s);

  IF SET_VGA_MODEX(0, ScreenX, ScreenY, 3) = 0 THEN
    ERROR_OUT('Unable to SET_VGA_MODEX' + S);

  SET_ACTIVE_PAGE(0);
  CLEAR_VGA_SCREEN(0);
  
  FOR X := 0 TO 60 DO
    Begin
      SET_DAC_REGISTER( 50 + X, 3 + X, 0, 60 - X);
      SET_DAC_REGISTER( 150 + X, 3 + X, 0, 60 - X);
    End;

  c := 0;
  DC := 1;
  FOR X := 0 TO ScreenX div 2 DO
    Begin
      DRAW_LINE( ScreenX div 2 - 1, ScreenY div 4, X, ScreenY - 1, c + 50);
      DRAW_LINE( ScreenX div 2, ScreenY div 4, ScreenX - X - 1, ScreenY - 1, c + 50);
      c := c + DC;
      IF (c = 0) OR (c = 60) THEN DC := -DC;
    End;

  COPY_PAGE( 0, 1);
  COPY_PAGE( 0, 2);

  Ch := #0;
  CurrentPage := 1;
  LastPage := 0;
  For c := 1 to 4 DO
    Set_Dac_Register(19+c,63-(c*10),0,0);

  While Ch <> #27 DO
    Begin
      Set_Active_Page(currentpage);
      If Right Then
        Begin
          XView := XView + XView_Change;
          If (XView > 38) OR (XView < 2) Then
            Begin
              XView_Change := -(XView_Change);
              Right := FALSE;
            End;
        End
      Else
        Begin
          YView := YView + YView_Change;
          If (YView > 38) OR (YView < 2) Then
            Begin
              YView_Change := -(YView_Change);
              Right := TRUE;
            End;
        End;

      Set_Window(currentpage,XView,YView);
      Set_Display_Page(currentpage);
      Set_Dac_Register(50 + PrevColor, 3 + PrevColor, 0, 60 - PrevColor);
      Set_Dac_Register(50 + SetColor, SetColor, 10, 63 - SetColor);
      Set_Dac_Register(150 + PrevColor, 3 + PrevColor, 0, 60 - PrevColor);
      Set_Dac_Register(150 + SetColor, 63, 63, SetColor);
      SetColor := SetColor + SDir;
      IF (SetColor = 60) OR (SetColor = 0) THEN SDir := -SDir;
      PrevColor := PrevColor + PDir;
      IF (PrevColor = 60) OR (PrevColor = 0) THEN PDir := -PDir;

      lastpage := (lastpage+1) MOD 2;
      currentpage := (currentpage+1) MOD 2;
    End;
END;

Begin
  Page_Demo;
  asm mov ah,0;mov al,3;int 16;end;
END.

Procedure Init_Sprites;
Var i : byte;
Begin
  For i := 1 to 64 DO
    Begin
      Obj[i].XPos := Random(300)+10;
      Obj[i].YPos := Random(200)+20;
      Obj[i].XDir := Random(10)-5;
      Obj[i].YDir := Random(10)-5;
      If (Obj[i].XDir = 0) AND (Obj[i].YDir = 0) Then
        Begin
          Obj[i].XDir := Random(5) + 1;
          Obj[i].YDir := Random(5) + 1;
        End;
      Obj[i].Shape := Random(4)+1;
      Obj[i].LastX := obj[i].XPos;
      Obj[i].LastY := obj[i].YPos;
    End;
End;

Procedure Set_Sprites(number : byte);
Var i : Byte;
Begin
  For i := 1 to number DO
    Begin
      obj[i].LastX := obj[i].XPos;
      obj[i].LastY := obj[i].YPos;
      obj[i].XPos := obj[i].XPos + obj[i].XDir;
      obj[i].YPos := obj[i].YPos + obj[i].YDir;
      If (obj[i].XPos > 335) OR (obj[i].XPos < 5 ) Then
        obj[i].XDir := -(obj[i].XDir);
      If (obj[i].YPos > 220) OR (obj[i].YPos < 5) Then
        obj[i].YDir := -(obj[i].YDir);
    End;
  For i := 1 to number DO
    Case obj[i].Shape of
      1 : TDraw_Bitmap(Circle_16,obj[i].XPos,obj[i].YPos,16,16);
      2 : TDraw_Bitmap(Square_16,obj[i].XPos,obj[i].YPos,16,16);
      3 : TDraw_Bitmap(Diamond,obj[i].XPos,obj[i].YPos,8,8);
      4 : TDraw_Bitmap(Rectangle,obj[i].XPos,obj[i].YPos,3,8);
    End;
End;

Procedure Remove_Sprites(p,number : byte);
Var i : byte;
Begin
  For i := 1 to number DO
    Copy_Bitmap(2,obj[i].LastX,obj[i].LastY,obj[i].LastX+16,obj[i].LastY+16,p,Obj[i].LastX,Obj[i].LastY);
End;
